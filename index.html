NETWORK CONTROL ENGINE

Router-enforced bandwidth limits and timed internet restrictions. No router changes occur until you confirm an action.
DISCONNECTED
NetworkRadar first identifies the active gateway/router using read-only local-network evidence. It then selects a compatible vendor adapter and shows exactly which controls that router supports. Vendor APIs differ, so unsupported models are identified where possible but are never modified through guessed or generic commands. Credentials remain in memory only. Timed restrictions expire on the router when the adapter supports router-side timers.

01 · IDENTIFY THE ROUTER FIRST

Read-only discovery of the current authorised default gateway. NetworkRadar checks HTTP response metadata and HTTPS management-service availability; it does not log in, change settings, or probe the whole subnet.

NetworkRadar verifies LAN/WAN interface lists before adding firewall rules. The pause rule is inserted before existing forward rules so it is evaluated before FastTrack. It only matches LAN-to-WAN traffic and leaves router management and local LAN traffic available.

04 · DEVICE BANDWIDTH

RouterOS Simple Queues use upload/download order. FastTrack bypasses Simple Queues. NetworkRadar now blocks the apply action while an enabled FastTrack rule is detected, then verifies the queue read-back before reporting configuration success. It never changes your firewall automatically.

05 · TEMPORARY DEVICE ACCESS

Pause internet access for one online device. Current observed global IPv6 addresses are also restricted when available.
Choose any whole-minute duration from 1 minute to 24 hours. The router enforces expiry even if NetworkRadar closes. IPv6 privacy addresses can rotate; incomplete dual-stack coverage requires explicit acknowledgement.

06 · NETWORK-WIDE CONTROL

Pause internet forwarding for the current authorised LAN subnet. Local device-to-device traffic and access to the router management interface are not targeted.
Choose any whole-minute duration from 1 minute to 24 hours. NetworkRadar displays the router's remaining timeout under Active Policies. The router automatically restores access when the timer expires, even if this application closes. Network-wide IPv6 control requires a global IPv6 prefix on the matching LAN interface; IPv4-only mode requires separate confirmation.

07 · NETWORK LOAD GENERATOR

Controlled iPerf3 UDP load testing for your authorised LAN or an explicitly authorised internet test server. This is a measured bandwidth test, not an unlimited request flood.
Idle. No test traffic is generated until you press START.
Measured throughput: — · Jitter: — · Packet loss: —
